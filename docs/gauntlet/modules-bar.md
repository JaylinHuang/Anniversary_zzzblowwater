# 功能标杆

群友周年站的功能标杆不是再加一个新频道，而是已有频道能走完。

对照这两条，缺一条即输：

1. 活动页（`/events`）：每个活动能看出「我已报名」或「我还没报名」，按钮文字跟着变。每场投票能看出我投过的那一项。没有活动、没有投票时，空状态写明下一步是谁来发布，而不是只有「还没有」。
2. 首页下半区的记忆回响：有归档时能翻出一句，并可以换一句。没有归档时，说明旁边有通往群聊归档的入口；换一句不会在空态里空转。同星期区块在加载中、为空、失败时都还在。
3. 活动能被版主关闭报名和重新开放。关闭后，没报名的人看到「已关闭报名」，已经报名的人仍能取消。
4. Meme 馆每张图能看出我赞过没有，按钮跟着变。一张都没有、或筛选后没有时，写出下一步，而不是空白。
5. 关闭报名之后，取消报名的写入必须在同一次数据库操作里根据当时的状态决定，不能先放行再在另一次写入里把报名插回去。
6. 夜街能看见粒子或短动画，只用现有的青、琥珀、深色。不挡住标题、铃与哲、登录框。系统开启「减少动态效果」时这些动效停掉。
7. 首页打卡能看到最近几天各自有没有盖章，数据来自已有的签到记录，不是写死的七个格子。
8. 祝福墙（`/wishes`）：每条祝福、每封胶囊能看出是不是我写的。今日还能贴几条，数字来自这个人今天已经贴上的条数；达到上限后再贴必须失败。条数检查和写入在同一次数据库操作里完成。墙上一条都没有时，写出下一步，而不是只有「还没有」。
9. 周年玩法（`/games`）：今天已经求过签的人，重新打开页面就能看见那张签。每道群梗题能看出我答过没有、对不对，状态来自答题记录。拼图写出我今天还剩几次点亮，次数来自今天的记录。没有题目时写出谁来出题。
10. 窄屏上夜街粒子仍能在标题、铃与哲、登录框之外被看见。减少动态效果时停，不挡点击。玩法页的扭蛋或拼图点亮有一段短动画，只用青、琥珀、深色。
11. Meme 馆每张已通过的图下面能看见已有评论：谁说的、说了什么，数据来自 `media_comments`。发出去的评论刷新后还在。没有评论时写出下一步。空白评论不能写入。
12. 自己封存的时间胶囊，在解锁日之前作者本人能看见原文；其他人仍只看见未解锁，不能提前公开。
13. 玩法页的「今天」和首页打卡用同一个本地日期。本地过了零点再打开，不应再显示昨天的签或昨天的点亮次数。求签的打卡加成也按这同一天判断。
14. 时间胶囊的解锁日按和首页打卡相同的本地日期判断。本地到了解锁日当天零点，所有人都能看见正文。作者提前看见自己原文、别人的未解锁正文不下发，这两条保持不变。
15. 「猜说话人」的每日出题上限按同一个本地日期计数。本地过了零点，已用次数从零开始，不能把昨天的题算进今天。
16. 首页打卡成功时，今天那一格有一段能看见的短动画，只用青、琥珀、深色。系统开启减少动态效果时直接显示已盖，不播放这段动画，也不挡住打卡按钮。
17. 和某位群友 Agent 单聊：打开页面就能看见今日已用轮次和上限，数字来自这个人今天发出的消息，日期和首页打卡的本地日相同。发送失败时，刚写上的那句不能留在对话里。达到上限后不能再发成功。
18. Meme 馆点赞：请求一直不返回时，这张图的赞数和按钮回到点之前的状态，不能一直停在请求中。请求返回并刷新后，仍以库里的赞过状态为准。
19. 趣味统计一条消息都没有时，话痨榜、深夜、词云都写出下一步（去导入群聊），而不是空白。有消息时，数字仍来自现有统计，不能写死。某一块自己的列表是空的（没有榜、没有时段柱、没有词）时，那一块也要写出下一步，不能因为别的块有数据就留白。时段里真有柱子、只是深夜比例为 0 时，仍显示这个 0。
20. 封存时间胶囊时，解锁日必须是 `YYYY-MM-DD`。不符合的日期不能写入。符合的日期仍按本地今天判断是否公开；别人的未解锁正文仍然不下发。

验收：读对应页面、客户端和接口。能打开 `http://127.0.0.1:3000/gate`、`/wishes`、`/games` 就打开看。
